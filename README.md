# 三式合参 · 梅花 奇门 六壬

一次起盘，三盘同屏，AI 三式合参解读。

- **一次起盘**：填写一次时间，同屏生成 梅花易数 / 奇门遁甲 / 大六壬 三盘
- **AI 合参解读**：三盘结构化数据一并提交，流式生成综合解读；接口由用户自行配置（OpenAI 兼容 Base URL / API Key / 模型），支持自由追问，可选「解读侧重」（感情 / 事业 / 财运 / 健康）
- **六爻 · 手摇起卦**：独立入口，手摇六次铜钱得六爻，自动装卦（本卦 / 变卦 / 六亲 / 六神 / 世应 / 纳甲 / 旬空），AI 解读

纯静态前端（HTML/CSS/JS），无需构建，直接打开 `index.html` 即可。

排盘引擎基于开源 [ChesterRa/mingpan](https://github.com/ChesterRa/mingpan)（Apache-2.0），经 esbuild 打包为浏览器单文件 `engine.js`。
